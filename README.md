# Out of Time — R.E.M. Tribute Band

This is the first functional trilingual website prototype.

## Publish
The site is static and can be hosted free on GitHub Pages or Cloudflare Pages.

## Before publishing
1. Replace `YOUR-BOOKING-EMAIL@example.com` in `index.html` with the band's booking email.
2. Replace the YouTube/video placeholder with the chosen live video embed.
3. Add the final Instagram/YouTube links in the footer.
4. Review the dates and add future concerts.
5. Keep the supplied logo and photos only if the band has the rights to use them.

Languages: German (default), English, French.
